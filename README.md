# 三个笨蛋过关 · 一个都不能少

单屏合作物理解谜网页小游戏：切换 🟦蓝方块 / 🩷粉团子 / ⭐黄星星，让三个家伙都走到出口。

- 6 个手工关卡 + 无尽笨蛋模式（随机生成机关）
- 三个角色各有物理性格：蓝方块重压推箱、粉团子弹跳刹不住、黄星星滑翔过沟
- 隐藏成就：连续撞蓝方块 20 次 → 「他真的生气了」

## 玩法
- ← → / A D 移动 · 空格 / ↑ / W 跳跃 · 长按空格＝黄星星滑翔
- Q / E 或 1 / 2 / 3 切换角色 · R 重开本关
