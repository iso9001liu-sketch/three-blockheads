# 三个大聪明过关

一个都不能少。单人切换三个角色的单屏合作物理解谜游戏。

双击 `启动游戏.cmd` 或 `index.html` 即可游玩，不需要安装依赖。也可在本目录运行 `node server.js`，打开 http://localhost:4173。

方向键 / A、D 移动；空格 / W / ↑ 跳跃。董高分长按跳跃滑翔。1、2、3 或点击角色卡切换，Tab 依次切换，R 重开，Esc 暂停。触屏有屏幕按钮。

8 个关卡均可在关卡手册选择。每关的「偷看一眼」提供完整解法，「投降看高玩操作」提供真实操作演示。

第四关「队友是弹簧」：借队友弹上高台解锁，推动货箱永久压桥。
第五关「渡船不等人」：留人供电，先遣队乘船接通对岸电源，再接走队友。
第六关「传送门接错了」：取中转电池、切换目的地、远端接力供电。
第七关「红灯别乱跑」：错峰光栅、惯性刹车、每人独立检查点。
第八关「谁来救救她」：粉团子卡住齿轮，另外两人操作升降台并锁桥，最后回到救援按钮释放队友。

无尽模式为带种子的程序化模板变体，不是调用 AI 服务。无需账号或联网。外部字体不可用时自动使用系统中文字体。IP 表情素材来自用户提供的三张规范图，保留在 assets 中；角色由游戏画布从原图实时取样。

开发：`node tests.js` 检查物理规则和全关卡流程。`node --check engine.js` / `node --check game.js` 检查语法。

点击「投降看高玩操作」可从头观看当前关卡的真实操作演示，带逐步解说。点击「我会了，让我来」或按移动/跳跃/切换键即可接管。演示和接管后的辅助通关不记入个人最好成绩；重新开始后恢复正常记录。

第三关现为「你先飞，我来砸」：取消首关的门和风扇流程，改用双乘客跷跷板。秦练习先在发射座停稳，艾改错跳砸蓝色冲击板将其送到第一座高台；再将董高分放上发射座，第二次重砸送到更高的接应点。普通站压无效。高玩演示及提示已同步更新。

页面按视口高度自动分配游戏区域，压缩标题与角色卡片，保持画布等比例显示；窄屏保留触屏操作。在极矮窗口或放大文字时允许滚动，避免截断关键操作。
